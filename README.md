# BEAMBE - Website portfolio

A multilingual B2B website for exploring medical products and preparing quotation requests.

**[Visit the live website](https://beambe.be/)**

## Project overview

BEAMBE presents its product range through a responsive catalogue, dedicated product pages and a quotation basket. The interface supports English, French and Dutch.

## Features

- **Product discovery:** 179 catalogue entries, comprising 68 urology products and 111 surgical sets.
- **Urology catalogue:** search, category filters, sorting and product comparison.
- **Surgical sets:** searchable names grouped by specialty, with quotation selection.
- **Quotation basket:** combine products from both categories, adjust quantities and prepare a structured request.
- **Three languages:** English, French and Dutch with a saved language preference.
- **Responsive layouts:** desktop, tablet, mobile and landscape.
- **Manufacturer images:** original-image viewing links on urology product pages.
- **Motion:** a scroll-controlled homepage sequence with forward/reverse playback, plus hover and reveal effects.

## Design approach

The site uses a navy and teal visual identity, clear catalogue navigation and concise procurement-oriented copy. Existing manufacturer product names and verified specifications are retained.

## About this repository

This public portfolio contains a written project overview and a link to the live website. Production source code, backend implementation, account configuration, internal reports, credentials, customer information and manufacturer artwork remain outside this repository.
